⑩ 대사 제외 유형 (자금수지 「통장 대사」의 미매칭 목록·자동 대사에서 뺄 유형 — 보증금처럼 매입 건이 없는 지급, 계산서 없는 사업소득 지급 등. 집계 버킷·월별 집계는 바뀌지 않습니다)
⑤ 역할 (인력 의뢰·후보자의 역할 구분 — 설명 칸에 동의어를 콤마로 적을 수 있습니다)
⑥ 업종 (고객사·프로젝트의 업종 구분)
⑦ 프로젝트 유형 (예: 차세대, 마이그레이션)
⑧ 실패 사유 (의뢰·후보가 실패·탈락한 이유)
🧱 시트 준비 (인력 의뢰·후보자 관리용 탭 18개와 기본 코드 — 처음 한 번 실행, 다시 눌러도 안전합니다)
🔁 코드 이관 (v3.1 — 저장된 거래·고정비 계획에 코드를 채웁니다)
① 위 「코드 전체 저장」으로 코드를 시트에 먼저 기록합니다. ② 시트 사본을 만듭니다. ③ 「미리보기」로 바뀔 건수와 이름을 못 찾는 항목을 확인합니다. ④ 「이관 확정」을 누르면 거래(S08_DETAIL)에 type_code, 고정비 계획(S06)에 item_code 열만 채우고 기존 열은 건드리지 않습니다. 이미 코드가 있는 행은 그대로 둡니다. 여러 번 실행해도 안전합니다.
인력 코드 이관 (v3.4) — 인력 시트의 역할·업종·프로젝트 유형·실패 사유 칸에 저장된 이름을 코드(RL-001 등)로 바꿉니다. 새 열을 만들지 않고 기존 칸의 값을 바꾸므로 시트 사본이 꼭 필요합니다. 이름을 못 찾은 값은 건드리지 않습니다. 여러 번 실행해도 안전합니다.
🔎 데이터 점검 (v3.5 — 읽기만 합니다. 시트를 고치지 않습니다)
인력·재무·코드 시트가 서로 맞는지 찾아서 어디를 봐야 하는지 알려 드립니다. 시트 수만큼 읽기 때문에 30초 안팎 걸릴 수 있습니다.
